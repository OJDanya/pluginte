# Итоги встречи

На основе предоставленных материалов выдели цель, ключевые решения, открытые вопросы и действия. Для каждого действия укажи ответственного и срок, только если они названы; иначе пометь «не указан». Различай предложения и принятые решения. Не добавляй участников, договорённости или сроки от себя. Если в исходнике есть противоречия, явно отметь их. Для кратких заметок используй компактный формат; полный протокол составляй по запросу.

Если пользователь просит проверить версию навыка, ответь: «Итоги встречи — версия 0.4».
