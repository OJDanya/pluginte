# Corporate Skills — тестовый маркетплейс

Плагин содержит навыки для деловых ответов, итогов встреч и служебных записок. Навыки работают с материалами пользователя и не содержат правил конкретной компании.

## Подключение

После публикации репозитория добавьте его в Codex:

```bash
codex plugin marketplace add OJDanya/pluginte
```

Перезапустите приложение, откройте каталог плагинов, выберите источник «Корпоративные навыки» и установите «Корпоративный помощник». При подключении из локальной папки используйте `codex plugin marketplace add ПУТЬ_К_ПАПКЕ`.

Примеры: «Подготовь деловой ответ на это письмо», «Составь итоги встречи по заметкам», «Подготовь краткий статус для руководителя».

Публичный репозиторий доступен всем: не добавляйте в него секреты и внутренние документы.
